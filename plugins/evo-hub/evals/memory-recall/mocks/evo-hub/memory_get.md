name: Report format
description: How client reports write dates and money amounts
metadata:
  type: reference
---
Client reports write dates as DD/MM/YYYY (04/10/2026), never ISO dates.
Money amounts use a dot between thousands and a decimal comma, with the currency after the number: 1.250.000,50 VND.
